# AGENTS.md

Welcome to MUI! This file provides guidance for AI agents and contributors working on this repository.

## Project Overview

MUI is a popular React UI framework that provides robust, customizable, and accessible components. We value inclusive design and strive to make our components usable by everyone.

## Development Setup

1. Clone the repository.
2. Install dependencies with `yarn install`.
3. Run the development server with `yarn dev`.

## Code Quality

- Follow the existing code style.
- Write tests for new features and bug fixes.
- Ensure TypeScript types are correct.
- Run `yarn lint` before committing.

## Commit Messages

- Use conventional commits (e.g., `fix:`, `feat:`, `docs:`).
- Keep messages concise and descriptive.

## Accessibility

- All components must meet WCAG 2.1 AA standards.
- Use semantic HTML and ARIA attributes where needed.
- Test with keyboard navigation and screen readers.

## Community

- Be respectful and inclusive.
- Help others by reviewing PRs and answering questions.

## Questions

For any questions, refer to the [contributing guidelines](CONTRIBUTING.md) or join our [Discord](https://mui.com/discord).
